# hyuntak03.github.io

Personal site. Plain HTML, CSS and a little JavaScript; no build step.

- `index.html` – the page
- `css/style.css` – styles (light/dark via `prefers-color-scheme`, or the toggle in the header)
- `js/main.js` – theme toggle, BibTeX copy, and the small "which way did it move?" demo
- `assets/img/pub/` – publication thumbnails

To preview locally, open `index.html` in a browser, or run `python3 -m http.server` in this directory.
