# hyuntak03.github.io

Personal site. Plain HTML, CSS and a little JavaScript; no build step.

- `index.html` – the page
- `css/style.css` – styles
- `js/main.js` – abstract/BibTeX toggles and the copy button
- `assets/img/pub/` – publication thumbnails

To preview locally, open `index.html` in a browser, or run `python3 -m http.server` in this directory.
